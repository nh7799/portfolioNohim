# Nohim Hasitha — Portfolio Website

This is my personal portfolio website, built with **React** and **Vite** to showcase my work, technical skills, academic progress, and professional readiness as a Computer Science student seeking a software engineering placement.

I created this portfolio to present my projects in a clear, structured, and recruiter-friendly way. It highlights my experience across frontend development, embedded systems, microcontroller projects, Java, Python, React, and practical problem-solving.

## Why I Built This

I wanted my portfolio to be more than a basic personal website. The goal was to create a professional space where employers can quickly understand:

- who I am
- what I can build
- the technologies I work with
- the projects I have completed
- my interest in software engineering, embedded systems, and robotics
- my readiness for a placement opportunity

This project also helped me improve my understanding of modern frontend development, component-based design, responsive layouts, deployment workflows, and professional presentation.

## Tech Stack

- **React** — for building reusable UI components
- **Vite** — for fast development and build performance
- **JavaScript** — for interactivity and project structure
- **CSS** — for responsive styling and visual design
- **Vercel** — for deployment and hosting
- **GitHub** — for version control and project management

## What I Learned

This was my first time deploying a portfolio using **Vercel**. Previously, I had only used GitHub Pages, so this project helped me step up my workflow and understand a more professional deployment process.

Through this project, I learned how to:

- structure a React project more clearly
- build and reuse components
- manage assets inside a Vite project
- deploy a live website using Vercel
- improve website presentation for recruiters
- create a portfolio that communicates both technical ability and career direction

## Purpose of the Portfolio

This portfolio is designed to support my placement applications by giving recruiters and employers a deeper view of my work beyond a CV. It brings together my projects, skills, academic achievements, and personal motivation in one place.

My aim is to keep improving it as I grow as a developer and continue building real projects that demonstrate practical engineering ability.
